Organizations often want to know what a group of customers would achieve if served by a different channel, using only observational data. The standard answer reweights the units of the other channel, with weights from a calibrated classifier. We show how this answer can fail when, as is typical of channel data, each channel records covariates in its own way. A variable recorded by only one channel breaks support by construction; the ideal classifier reveals it, and dropping the variable is safe when it does not predict the basic-channel outcome given the others. A variable measured with a different instrument in each channel is worse: support can survive, and the estimator converges to a shifted value that no analysis of the observed data can distinguish from the truth. We derive that shift exactly. With public data in which both instruments exist for the same people (self-reported and measured body mass index in NHANES), the derived shift approximately matches the observed bias, and the usual overlap diagnostics improve rather than flag it. Along the way, we read support failure in the classifier through the Lebesgue decomposition, show that the doubly robust estimator silently extrapolates where support fails, give weights for target groups defined by a known score cutoff, and adapt sensitivity bounds for unobserved confounding. An experimental benchmark (NSW/CPS) and a simulation whose predictions were registered before running it (we report those that failed) complete the evidence.
